# Intersaberes Play

Plugin do tipo **atividade (mod)** para o Moodle.

##  Sobre o plugin

O **Intersaberes Play** permite adicionar, dentro de um curso no Moodle, uma atividade dedicada à divulgação de conteúdos da plataforma **Intersaberes Play**.

A atividade funciona como um ponto de integração e apresentação, permitindo que alunos e professores conheçam cursos e disciplinas disponíveis na plataforma.

Além disso, o plugin já acompanha um **curso e uma disciplina de exemplo**, possibilitando que administradores e professores testem o funcionamento imediatamente após a instalação.

##  Objetivo

Facilitar a divulgação e demonstração dos conteúdos da plataforma Intersaberes Play dentro do ambiente Moodle, incentivando a avaliação e possível adoção da solução completa.

##  Funcionalidades

- Criação de atividade "Intersaberes Play" dentro dos cursos
- Inclusão de conteúdo demonstrativo integrado à plataforma
- Disponibilização de curso e disciplina de exemplo para testes
- Interface simples para professores adicionarem a atividade

##  Instalação

1. Faça upload da pasta do plugin para o diretório: /mod/intersaberesplay
2. Acesse o Moodle como administrador
3. Acesse **Administração do site > Plugins**
4. Siga as instruções para concluir a instalação

##  Como usar

1. Acesse um curso no Moodle
2. Ative o modo de edição
3. Clique em **"Adicionar atividade ou recurso"**
4. Selecione **"Intersaberes Play"**
5. Configure conforme necessário e salve

##  Conteúdo de demonstração

Após a instalação, o plugin disponibiliza conteúdo de exemplo (curso e disciplina) para:

- Testar a funcionalidade
- Avaliar a experiência do usuário
- Demonstrar o potencial da plataforma Intersaberes Play
